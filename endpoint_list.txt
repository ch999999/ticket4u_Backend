Showings
GET:
- /showings/all 0
  - fetches all showings
- /showings/{showing_id} 0
  - fetches a showing by it's id
- /showings/{showing_id}/movie 0
  - fetches the movie being shown in the showing
- /showings/{showing_id}/cinema 0
  - fetches the cinema the showing is being held at
- /showings/{showing_id}/hall 0
  - fetches the hall the showing is being held at
- /showings/{showing_id}/seats = /halls/{hall_id}/seats 0
  - fetches all the seats in the hall the showing is being held at
- /showings/{showing_id}/seats/available 0
  - fetches all the available seats in the hall the showing is being held at
- /showings/{showing_id}/tickets (auth required) 0
  - fetches all the tickets for a showing belonging to the user
